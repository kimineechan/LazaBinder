# LazaBinder v1.0.1

Maintenance release. The project has been renamed from **LazarusBinder** to **LazaBinder**. The program, build, documentation, and release assets now use the new name. Functionality is unchanged from v1.0.0.

## Changed

- Renamed the application to LazaBinder throughout, including the Windows build output (`LazaBinder.exe`) and the release archive (`LazaBinder-v1.0.1-windows-x64.zip`).

## Included

- Combine two EXEs into one file, preserving the original input files.
- Start both programs together or launch the second after the first exits.
- Request administrator rights for the final combined EXE through Windows UAC.
- Start the applications without an extra launcher window.
- Apply a custom ICO during bundling or save an existing bundle with a new icon.
- Extract complete icon groups from EXE/DLL files, including their original resolutions.

## Download

Download `LazaBinder-v1.0.1-windows-x64.zip`, extract it, and open `LazaBinder.exe`. The builder targets 64-bit Windows 10 and Windows 11. No development tools or installer are required to use it.

`SHA256SUMS.txt` lists the ZIP and EXE hashes. The ZIP also includes the EXE's checksum.

## Compatibility

Only the two selected EXEs are included; external DLLs, data files, plugins, and installed runtimes remain the responsibility of the selected applications. In administrator mode, both applications inherit the final EXE's elevated permissions.

See `VALIDATION.md` for performed checks and the testing boundary.
