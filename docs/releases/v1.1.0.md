# LazaBinder v1.1.0

A new window, in the style of LazaReplay and LazaScrub. Bundles are made exactly as before, and bundles made by earlier versions still open.

## Changed

- The window is black and see-through, with what is behind it blurred so the text stays readable, and has rounded controls.
- Switches replace the tick boxes, and the list of icon groups scrolls when a program holds many.
- The whole window can be worked from the keyboard: Tab, Enter, Space, the arrow keys, and Ctrl + Tab to change section.
- The button for the thing to do next is the light one.

## Download

Download `LazaBinder-v1.1.0-windows-x64.zip`, extract it, and open `LazaBinder.exe`. It targets 64-bit Windows 10 and Windows 11. No development tools or installer are required.

`SHA256SUMS.txt` lists the hashes of the ZIP and of the program.

## Compatibility

The window was tested on Windows 10 build 19045 at 100% scale. It has not been tested on Windows 11. It draws its own controls, so screen readers cannot read them. The dialogs for choosing and saving files, and the boxes that report a result, are the standard ones of Windows.

See `VALIDATION.md` for the checks that were run and where they stop.
